# Example: wing aspect-ratio sweep

Relations for a simple reference geometry: aspect ratio AR=b^2/S and mean geometric chord c=S/b. If area S is controlled, varying AR implies b=sqrt(AR*S) and c=sqrt(S/AR). If speed and fluid properties remain fixed, Reynolds number based on c changes too.

Therefore a fixed-area/fixed-speed aspect-ratio sweep does not also have fixed chord-based Reynolds number. Either allow Reynolds number to vary and state that coupling, or adjust another quantity with an explicit reason. The reference chord for a non-rectangular wing requires its own definition.

A plan contains the question, independent AR values, controlled area and operating state, derived span/chord/Re, response metrics, and acceptance evidence. A run record links exact geometry, model settings, outputs, and warnings.

A calculated trend from an unvalidated approximation supports a model-specific sensitivity statement. It does not establish real-flight endurance or measured aerodynamic accuracy.
